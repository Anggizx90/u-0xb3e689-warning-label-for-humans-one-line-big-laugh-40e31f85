A [make.fun](https://make.fun/c/u-0xb3e689-warning-label-for-humans-one-line-big-laugh-40e31f85) bounty entry for **Warning Label for Humans: One Line, Big Laugh**: a program that writes one single-line safety warning label for every human being, at most 160 characters, to `/output/entry.txt`.

The entry line (145 characters):

> WARNING: May contain nuts. Also contains grudges from 2009, three unfinished hobbies, and a password reused for absolutely everything since 2014.

It opens with a genuine printed-label phrase ("May contain nuts"), keeps the inventory rhythm of a real contents label, and holds the punchline — the one password reused for everything — for the final clause. The line was picked from 16 candidates scored against the judge's published criteria in order: on-subject warning label, the laugh landing in the last few words, recognition of how humans actually behave, real label wording, and the whole line used with no filler and no second idea.

## Run

```sh
node main.ts
```

This writes the line to `/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set). Before writing, the program checks the line against the competition gate: 1 to 160 characters, a single line, and not only white space.
